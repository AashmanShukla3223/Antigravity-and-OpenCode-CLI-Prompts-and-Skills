macOS 27 Golden Gate

A high-fidelity web-based macOS simulator

macOS 27 Golden Gate is a silicon-native OS simulation built with React, TypeScript, Framer Motion, and Tailwind CSS. It runs entirely in your browser — no downloads required.

52 Built-in Apps

Finder, Safari, Mail, Messages, FaceTime, Calendar, Photos, Music, Podcasts, App Store, System Settings, Maps, Weather, Calculator, Notes, Reminders, Terminal, Activity Monitor, iPhone Mirroring, and 33 more.

Key Features

  • Dynamic Island with 13 modes (music, notifications, camera, phone, alarms, timers, downloads, OTA updates, AirPlay, recording, stopwatch, live activities)
  • iPhone 17 Pro Max Mirroring with iOS home screen, lock screen, widgets, and Control Center
  • OTA Internet Update system with semver comparison and progress indicators
  • Cross-tab Continuity: AirDrop, Handoff, and Universal Control via BroadcastChannel API
  • Mission Control, Stage Manager, and Hot Corners for window management
  • Dynamic wallpaper engine with time-of-day awareness
  • Virtual File System with persistent localStorage storage
  • Full boot lifecycle: Boot Sequence → Setup Assistant → Login → Desktop → Recovery → Activation Lock
  • Hardware simulation: Battery API, Performance Memory API, Storage Estimation API
